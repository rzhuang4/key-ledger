Full safety note

The instruction sheet says the first remote accepted in this session erases remotes the truck already knows. A wrong sequence can wipe working remotes or never enter program mode. If the doors do not lock and unlock to confirm program mode, stop. A locksmith or dealer can finish the job.

  1. Close all the doors.[1]
  2. Insert the ignition key into the ignition lock cylinder.[1]
  3. Press and hold the door unlock switch.[1]
  4. While holding that switch in the unlock position, cycle the ignition ON, OFF, ON, OFF.[1]
  5. Release the unlock switch.

Fob will not program

The locks do not cycle at all

North Coast Keyless's 2005 Silverado programming page says that if the locks never cycle, you may be turning the key too quickly or too slowly, the keyless-entry system may have a problem, or the truck may not have keyless entry. It says to check with a locksmith or a dealer. The opened GM service pages say the locks should cycle when you release the unlock switch. They do not print this split.[6][4][5]

The locks cycle before you release the unlock switch

The same North Coast page says a cycle before you release the unlock button means the truck has not entered programming mode, and you start over. If the locks keep cycling before you release the button, that page says the keyless-entry system has a problem and a locksmith or dealer has to program the remotes. The opened GM service pages do not print that early-cycle test.[6]

No second response from the remote

North Coast says to hold Lock and Unlock together for up to 30 seconds, until the locks cycle again. The opened GM service pages say that confirmation comes after about 15 seconds. Neither page gives a separate test for a remote that stays silent after the locks have already cycled to confirm program mode. That case is unknown here.[6][4][5]

About this vehicle

On-board programming

Program every remote you want to keep in one session. The sheet says transmitters already stored are erased when the first new transmitter is accepted. This sequence programs the keyless remote only. [1]

You need a compatible remote and the ignition key that turns the lock cylinder. This does not cut a metal key.

Safety. The instruction sheet says the first remote accepted in this session erases remotes the truck already knows. A wrong sequence can wipe working remotes or never enter program mode. If the doors do not lock and unlock to confirm program mode, stop. A locksmith or dealer can finish the job.

The sheet's own heading is part number 21997127, and it includes 2003-2007 Chevrolet Silverado 1500 among the vehicles that can use the printed sequence. It tells owners of a 2005-2006 Equinox, 2006 Torrent, and 2002-2003 Vue to use a scan tool instead. Those exceptions are not this truck. [1]

Metal ignition key

B102 Keysolved's 1999-2007 Silverado 1500 page lists the ignition key as a plain steel B102 with no chip, and the system as GM Passlock in the body control module rather than a transponder in the key. It says that covers all 1999-2006 trucks and the 2007 Classic. The same page lists a separate 3-button keyless remote, FCC LHJ011, for 2003-2006 and the 2007 Classic. This does not add steps for cutting that blade.[9]

The keyless-entry remote on a 2003-2006 Chevrolet Silverado 1500 can be programmed at the ignition, without a scan tool. An instruction sheet for part 21997127 lists that truck and prints the button sequence. The remote is a separate fob, not the metal ignition key.

Light-duty Silverado 1500, 2003 through 2006, US market. The same instruction sheet also names 2007 Silverado 1500 and several HD models. Those trucks are outside this page. A truck that was not built with keyless entry has nothing for this remote to talk to.

Which one to buy

3-button keyless-entry remote

  1. The FCC ID on the remote, or the ID the seller states, should be LHJ011. A seller-listed ID is not the grant ID.
  2. The button count should match this file: 3.
  3. The frequency should match this file: 315 MHz.

A seller may call a remote aftermarket or re-cased OEM electronics. This directory repeats that wording only when the listing says it, and it does not test the claim. In a May 14, 2024 r/Locksmith thread about a 2009 Suzuki, shops did not agree. One locksmith wrote that some shops will program a fob you bring and some will not, and that you still pay if it does not program. Another wrote that they charge a programming fee whether or not the supplied remote works. Another wrote that a shop may not warranty a key you bring and may still charge close to a full price. One said an online fob is often the wrong frequency. That thread is not a rule for the vehicles on this site.

r/Locksmith discussion, May 14, 2024

A lower hardware price is not a promise that a locksmith will program or warranty that fob. A May 14, 2024 r/Locksmith thread shows shops that do not agree about customer-supplied fobs.
