Full safety note

There is no on-board sequence on this page. Guessing ignition cycles or button combinations can leave a key unrecognized, and a locksmith or Honda dealer then has to recover it with the right tool. Stop if you do not have that tool and the password or immobilizer code the service procedure uses.

A 2012 CR-V LX service procedure and a 2012-2016 CR-V service reprint both say the HDS is required to register immobilizer keys. Programming the immobilizer also programs the keyless transmitter. The control unit stores up to six immobilizer keys. Adding a key, in the 2012 LX text, takes a key that is already registered plus the first password from Honda's iN system. If every key is lost, that text calls for the immobilizer PCM code. Those are shop steps. They are not reprinted here as something to try in a driveway.

Which one to buy

3-button remote-head key

  1. The FCC ID on the remote, or the ID the seller states, should be MLBHLIK-1T. A seller-listed ID is not the grant ID.
  2. The button count should match this file: 3.
  3. The frequency should match this file: 313.85 MHz.

4-button remote-head key

  1. The FCC ID on the remote, or the ID the seller states, should be MLBHLIK6-1T. A seller-listed ID is not the grant ID.
  2. The button count should match this file: 4.
  3. The frequency should match this file: 313.85 MHz.

A seller may call a remote aftermarket or re-cased OEM electronics. This directory repeats that wording only when the listing says it, and it does not test the claim. In a May 14, 2024 r/Locksmith thread about a 2009 Suzuki, shops did not agree. One locksmith wrote that some shops will program a fob you bring and some will not, and that you still pay if it does not program. Another wrote that they charge a programming fee whether or not the supplied remote works. Another wrote that a shop may not warranty a key you bring and may still charge close to a full price. One said an online fob is often the wrong frequency. That thread is not a rule for the vehicles on this site.

r/Locksmith discussion, May 14, 2024

Keys that sellers and grants describe

3-button remote-head key

Listed by sellers for 2012-2013, and by some for 2007-2013

Key type
Remote head key. Car Keys Express calls this a remote and key combo, also known as a remote-head key: an ignition key with a transponder plus Lock, Unlock, and Panic. Tom's Key sells the same kind of 3-button key and says it will not work on a push-button start.[5][6]
FCC ID
  • MLBHLIK-1T · OEM grant ID FCC grant to Honda Lock Mfg. Co., Ltd., model HLIK-1T, remote keyless entry transmitter. Grant date May 9, 2006. Frequency on the grant is 313.85 MHz. Car Keys Express, Tom's Key, and MK3 all print MLBHLIK-1T on CR-V remote-head listings.[3][5][6][9]
Part numbers
  • 35118-T0A-A00 — MK3 lists this as the OEM part for a 2012-2013 CR-V remote. The US sellers checked below print different numbers. Not confirmed on a Honda parts fiche.[9]
  • 35111-SWA-306 — Tom's Key lists this as the part its 3-button aftermarket key replaces. The listing also covers other Honda models, not only the CR-V.[6]
  • HLIK-1T — Car Keys Express lists HLIK-1T as a part number. That string is also the FCC model. Treat it as the seller's label, not as proof it is the Honda parts-counter number.[5]
  • 5938192 — Strattec number printed by Car Keys Express.[5]
Battery
CR1616 MK3 states CR1616. The FCC grant does not name the cell. The Tom's Key and Car Keys Express pages checked for this key do not list a battery.[9]

Amazon search for this battery

Frequency
313.85 MHz That is the grant frequency. MK3's product page says 315 MHz for the same FCC ID. Use the number on the grant, and match the ID on your key rather than a rounded seller frequency.[3][9]

Tom's Key lists the chip as Philips 46. MK3 lists transponder ID PCF7961A. Those claims were not checked against a Honda document, and they are not the same label. [6][9]

Tom's Key also prints 'MLBHL1K-1T' next to MLBHLIK-1T. The extra spelling does not match the FCC grant. Read the ID on your key character by character. [6]
