About this vehicle

On-board programming

On-board programming is published for an integrated keyhead transmitter when two coded keys already work. Without those two keys, both the 2013 guide transcription and Ford's how-to page send you to a dealer. [1][2]

You need two previously programmed coded keys and one new unprogrammed integrated keyhead transmitter or SecuriLock key. The blade still has to be cut. Car and Truck Remotes says they do not cut or program the remote they sell.

Safety. Hold times do not match across the sources on this page. A wrong sequence can leave the new key unprogrammed. The 2013 transcription says the procedure programs both the engine immobilizer code and the remote buttons, and that it works only with integrated keyhead transmitters or standard SecuriLock keys. It allows a maximum of eight coded keys, and only four of those eight can be integrated keyhead transmitters. [1]

Car and Truck Remotes' 2013 F-150 listing says 'On Board Programming: No' and that the remote must be professionally cut and programmed by a locksmith. That contradicts the owner's guide transcription and Ford's how-to. The seller also says a dealer may refuse to program an aftermarket remote. [4]

A 2013 Ford PATS job aid lists the F-150 for 2011-2013 and says only integrated keyhead transmitters can be programmed manually. It does not print a separate-fob procedure for this truck, and 2014 is not on that chart. This page does not add a separate-remote sequence. [5]

Which one to buy

3-button remote-head key

  1. The FCC ID on the remote, or the ID the seller states, should be CWTWB1U793. A seller-listed ID is not the grant ID.
  2. The button count should match this file: 3.
  3. The frequency should match this file: 315 MHz.

A seller may call a remote aftermarket or re-cased OEM electronics. This directory repeats that wording only when the listing says it, and it does not test the claim. In a May 14, 2024 r/Locksmith thread about a 2009 Suzuki, shops did not agree. One locksmith wrote that some shops will program a fob you bring and some will not, and that you still pay if it does not program. Another wrote that they charge a programming fee whether or not the supplied remote works. Another wrote that a shop may not warranty a key you bring and may still charge close to a full price. One said an online fob is often the wrong frequency. That thread is not a rule for the vehicles on this site.

Key type
Remote head key. The 2013 owner's guide calls the equipped key an integrated keyhead transmitter: it starts the truck and operates the locks. Car and Truck Remotes sells a 3-button remote (Lock, Unlock, Panic) for a turn-the-key F-150 and says it replaces that factory remote.
