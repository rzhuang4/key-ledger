2004–2008 Ford F-150

Program it yourself?

Yes, for the separate remote. The ignition-cycle procedure does not require two programmed keys, and it does not program the SecuriLock chip.

A 2007 F-150 service procedure and the 2006 owner's guide both print a tool-free remote sequence. You need a key that turns the ignition. You do not need two programmed keys, and you do not need a working remote if the doors can be unlocked with the power lock switch. Aftermarket owner reports are separate from that procedure.

This page does not apply to a 2004 Heritage, to a 2011-2014 integrated key, or to programming the SecuriLock chip that starts the engine.

Full safety note

The service page allows four remotes and the 2006 guide says six. A remote left out of the session stops working. If the locks never cycle, stop and have a locksmith or dealer check the truck. The spare-key procedure is a different job.

On-board programming

flyndubya89 wrote that an eBay remote for a 2006 SuperCrew had 'No problems getting it working and hasn't failed yet.' Nola 07 FX4 wrote that an eBay remote, about $10 with shipping, was 'working fine' within 2 minutes. barriosman wrote that two Amazon remotes were 'working in 10 minutes' and did not state the truck's year. Barn Queen, writing about a 2004, said the Ford dealer charges almost $75. That is one owner's statement, not a posted price. [3][4]

  1. Program every remote in the same session.
    More

    Program every remote in the same session. The 2007 procedure says this can be done with a scan tool or with the steps below. Unlock the truck electronically with a remote, the keypad if the truck has one, or the door lock switch while the driver door is open. [1]

  2. Turn the key from OFF to RUN eight times within 10 seconds.
    More

    Turn the key from OFF to RUN eight times within 10 seconds. The eighth turn ends in RUN. If the truck enters program mode, the doors lock and then unlock. [1]

  3. Within 20 seconds, press any button on a remote.
    More

    Within 20 seconds, press any button on a remote. The doors lock and then unlock to confirm that remote. Repeat for each remote. Do not try to program more than four. [1]

  4. If the locks do not answer a remote, wait several seconds and press a button again.
    More

    If the locks do not answer a remote, wait several seconds and press a button again. The mode ends when the key is turned OFF, when 20 seconds pass, or when four remotes have been programmed. [1]

Fob will not program

The locks never cycle

The 2007 procedure says the doors lock and then unlock when program mode starts. If they do not, the truck did not enter the mode. The 2006 guide starts by unlocking the doors with the power lock control.[1][2]

An old remote stopped working

The 2006 guide says transmitters that are not present during programming will no longer operate the vehicle. Bring every remote you still want.[2]

About this vehicle

On-board programming

The numbered steps are the 2007 F-150 factory procedure for the remote transmitter. The 2006 owner's guide transcription prints the same kind of sequence and a different transmitter limit. Forum posts are owner reports. [1][2]

Have every remote you want to keep. Remotes that are not present are dropped. A key has to turn the ignition. The doors have to be unlocked before you start. Two programmed keys are required only for the separate spare-key procedure.

Safety. The service page allows four remotes and the 2006 guide says six. A remote left out of the session stops working. If the locks never cycle, stop and have a locksmith or dealer check the truck. The spare-key procedure is a different job.

The 2006 F-150 Owner's Guide transcription says to have all remote transmitters available, maximum of six. Transmitters that are not present will no longer operate the vehicle. It says to unlock the doors with the power door lock control, then cycle the ignition from 1 (OFF/LOCK) to 3 (ON) eight times within 10 seconds, ending in ON. It does not mention a scan tool. This site did not open Ford's PDF. [2]

The same 2006 guide's spare-key section is SecuriLock, not the remote. It requires two previously programmed coded keys. If those two keys are not available, the guide says to take the truck to a dealer. [2]

Owner reports, not the procedure: a 2006 SuperCrew owner and a 2007 FX4 owner wrote that eBay remotes programmed. One Amazon buyer wrote that two remotes worked in 10 minutes and did not state the year. A 2004 owner wrote that the dealer charges almost $75. That last figure is not a posted price. [3][4]

Metal ignition key

The 2006 guide calls SecuriLock an engine immobilization system. A coded key has to be programmed before it will start the engine. Programming a spare key yourself requires two previously programmed coded keys. The remote steps do not do that job. No blade code was on the pages opened.[2]

The new-style 2004-2008 F-150 uses a separate keyless remote. A 2007 factory procedure and a 2006 owner's guide both print an ignition-cycle sequence that does not ask for two programmed keys. That sequence does not program the SecuriLock chip. The 2004 Heritage is a different truck.

New-style Ford F-150, 2004 through 2008, US market, with a separate keyless remote. Ford Parts Connect lists transmitter 8L3Z-15K601-B for F150 NEW STYLE 2004-08. This page does not cover the 2004 F-150 Heritage. It does not cover 2011-2014 trucks, which use an integrated key and have their own page. It does not program the SecuriLock key. The 2006 owner's guide puts spare-key programming in a different section, and that section requires two previously programmed coded keys.
